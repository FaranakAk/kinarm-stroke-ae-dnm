# kinarm-stroke-ae-dnm
# Autoencoder-based Stroke vs Control classification (Kinarm VGR) + DNM Visualization

End-to-end code to (1) train and evaluate an autoencoder-based binary classifier (stroke vs control) on Kinarm VGR report features and (2) train and generate 2D Deep Neural Map (DNM) visualizations as published in:


Akbarifar, F., Dukelow, S. P., Mousavi, P., & Scott, S. H. (2021). Computer-aided identification of stroke-associated motor impairments using a virtual reality augmented robotic system. Computer Methods in Biomechanics and Biomedical Engineering: Imaging & Visualization, 10(3), 252–259. https://doi.org/10.1080/21681163.2021.2009377
